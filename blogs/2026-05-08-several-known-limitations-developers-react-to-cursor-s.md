Cursor, the AI-powered code editor, released last Wednesday a dedicated SDK that lets developers build agents using the same runtime, harness, and models that power Cursor itself — part of what appears to be a broader push to grow beyond its IDE roots. This comes as Cursor CEO Michael Truell welcomes what it has heralded as the “third era” of software development, now driven by AI-assisted code tools.
