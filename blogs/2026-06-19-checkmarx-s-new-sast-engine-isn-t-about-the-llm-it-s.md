Checkmarx unveiled a new SAST engine combining deterministic rules, LLM-based scanning, and a findings analysis engine to classify true versus false positives. The real innovation lies in orchestration rather than the LLM itself, addressing the noise created by AI-accelerated development where code volume has surged.
