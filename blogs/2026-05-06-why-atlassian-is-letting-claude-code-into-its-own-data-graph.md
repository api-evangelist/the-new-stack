Atlassian wants the autonomous, long-running agents that developers use in tools like Claude Code to work for everyone else. At its Team ’26 conference in Anaheim on Wednesday, the company is rolling out Max, a new mode in Rovo Chat that Atlassian’s head of product for AI, Jamil Valliani, describes as a “mini Claude Code” running “in the cloud with Teamwork Graph context built in.
